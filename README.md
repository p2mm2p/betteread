# BettRead

A browser extension that helps you focus while reading web pages.

It highlights one sentence at a time and supports `vim` style navigation.

## Features

- `CTRL` + `r`: start reading
- `j`: move down one line, to its first sentence
- `k`: move up one line, to its first sentence
- `h`: move left one sentence; at a line's first sentence, go to the previous line's last sentence
- `l`: move right one sentence; at a line's last sentence, go to the next line's first sentence
- Highlight style: underline or block
- Highlight color: hexadecimal input
