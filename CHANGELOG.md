## [0.1.0] - 2026-11-18

- Press `Alt+R` or click the toolbar icon to start or stop reading mode.
- Use Vim-style keys to move the reading position (`j`/`k` move down/up one paragraph, `h`/`l` move to the previous/next sentence).
- Use the settings page to set the highlight style (block/underline) and highlight color (hex value).
